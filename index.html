유어스 (You, Us) - 팀 프로젝트

GitHub ↗ Demo ↗

기존 쇼핑몰은 카테고리·가격 필터 중심이라 사용자가 스스로 답을 찾아야 하는 구조입니다. 유어스는 이 문제를 해결하기 위해, 받는 사람·상황·예산을 문항 선택 방식으로 입력하면 OpenAI API가 답변을 분석·태그화해 조건에 맞는 상품을 카드 형태로 추천하는 선물 쇼핑몰입니다. AI를 마케팅 요소가 아닌 핵심 기능으로 설계에 포함한 것이 특징입니다. 백엔드는 제공된 API 서버를 활용한 프론트엔드 중심 프로젝트입니다.

4인 팀에서 PM을 맡아 일정·우선순위·방향성을 조율했고, 인트로 · AI 추천 테스트 · 로그인 · 회원가입 · 주문결제 페이지를 직접 개발했습니다.

굿데이 (Good Day) - 개인 프로젝트

GitHub ↗ Demo ↗

친구들과 놀러 나갈 코스를 직접 만들고 공유할 수 있는 풀스택 개인 프로젝트입니다. Supabase(PostgreSQL + Auth + RLS)로 백엔드를 직접 구성했습니다. 네이버 장소 검색으로 원하는 장소를 추가하고 드래그 앤 드롭으로 방문 순서를 자유롭게 조정할 수 있습니다. 완성된 코스는 Google Maps 기반으로 도보·대중교통 경로를 구간별로 안내하며, URL 복사 또는 카카오톡 공유 시 OG 미리보기(제목·설명·이미지)가 함께 표시됩니다.

주요 기능으로는 네이버 장소 검색 및 드래그 순서 변경, Google Maps + TMap 기반 경로 안내, 지도에서 주변 코스 탐색, 좋아요 수 기준 인기 코스 랭킹, 북마크·저장 장소 관리, 자동로그인(세션 유지 방식 선택) 등이 있습니다.

Google Maps API, TMap API, 네이버 검색 API, Google Geocoding API 등 다양한 외부 API를 직접 연동하며 CORS 처리, 서버/클라이언트 환경 분리, API 인증 방식 차이를 경험했습니다. Supabase PostgreSQL + RLS 정책으로 인증 기반 데이터 접근 제어를 설계했고, Next.js App Router의 generateMetadata를 활용한 SSR 기반 OG 메타 생성도 직접 구성했습니다.
