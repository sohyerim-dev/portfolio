"빠르게 이해하고, 끝까지 구현합니다."

서비스를 단순히 화면 단위로 구현하기보다, 사용자 흐름과 전체 구조를 함께 이해하며 문제를 해결하는 데 강점이 있습니다.

프로젝트를 진행할 때는 기능 구현에만 머무르지 않고 "왜 이 흐름이 필요한가", "사용자는 어디서 불편함을 느끼는가"를 함께 고민합니다. 실제 프로젝트에서는 OpenAI API, 인증(Auth), 결제 시스템, 지도 API 등을 직접 연동하며 서비스 전반의 흐름을 구현해왔습니다.

또한 팀 프로젝트에서는 PL·PM 역할을 맡아 일정 조율, 기능 우선순위 정리, 협업 흐름 관리까지 경험했습니다. 기술적인 문제뿐 아니라 프로젝트 전체가 안정적으로 완성될 수 있도록 방향을 정리하고 조율하는 역할에 흥미를 느낍니다.

새로운 기술 역시 단순히 학습하는 데 그치지 않고, 직접 구현하고 부딪히며 빠르게 이해하고 적용하는 개발자이고자 합니다.
